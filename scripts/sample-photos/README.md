# Sample shelf photos

Drop one or more JPEG/PNG images of retail shelves here for the verify
script and ad-hoc testing. Filenames like `shelf-01.jpg`, `shelf-02.jpg` are
fine — nothing reads them automatically (you pick from the UI).

If you don't have a real shelf photo handy, the Wikipedia entries for
"Supermarket shelf" or "Retail merchandising" have CC-licensed photos that
work for a demo.

These photos are NOT committed (the directory is empty by default).
